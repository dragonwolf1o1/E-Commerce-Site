# E-Commerce-Site

Charlok Vault is now a responsive multi-page luxury car marketplace built as a static website.

## What's New

- Redesigned the full website with a premium editorial look and responsive layout.
- Organized the project into a cleaner structure with shared assets in `assets/css`, `assets/js`, and `assets/images/cars`.
- Expanded the site into multiple pages:
  - `index.html`
  - `collection.html`
  - `experience.html`
  - `contact.html`
  - `login.html`
  - `register.html`
  - `success.html`
- Added live collection filtering and search.
- Added a Saved Garage feature using `localStorage`.
- Added a custom Curator Lab that recommends a car based on user preferences.
